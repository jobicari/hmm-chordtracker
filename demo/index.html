Chord Tracker

Real-time chord tracking. A neural network labels every 93 ms frame on its own, so its chords flicker; an HMM / Viterbi decoder that waits for a few more frames smooths them into steady chords.

The chords were computed ahead of time, because the model does not run in the browser. The page shows each chord only from the moment the live system would have output it, never earlier.
