Chord Tracker

Real-time chord tracking. A neural network labels every 93 ms frame on its own, so its chords flicker; an HMM / Viterbi decoder that waits for a few more frames smooths them into steady chords.

Computed ahead of time, because the model does not run in the browser: each chord appears only from the moment the live system would have output it, never earlier.

Analysis pipeline: how each chord is computed
    Notes and limitations
    • Chords: major and minor triads only, and always a chord: no "no chord", no sevenths or other qualities. A seventh chord is shown as its triad at best.
    • Training: the network was trained on the RWC Popular Music and GuitarSet training takes. The prepared samples are GuitarSet validation takes, which it did not train on.
    • Real time: the chords were computed ahead of time and are revealed when the live system would output them. After a seek, the page shows the decisions of an uninterrupted run; a live system restarted at that point would need a few seconds to settle (running level, tuning, memory).
    • Your files: analysed on this computer by the demo server with the same model; some formats are lossy, which changes the chords slightly. No reference annotations exist for them.
    • No scores here: the page shows outputs only. Accuracy figures, measured on validation and test songs, are in the project's reports.
