    Notes and limitations
    • Chords:
    • Spelling: each root is always spelled the same way, whatever the key (C#, Eb, F#, Ab, Bb), and the reference row uses the same spelling. A song in Eb minor shows C#7 for Db7 and F# for Gb.
    • Training: The prepared samples are GuitarSet validation takes, which it did not train on.
    • Real time: the chords are decided live by the demo server as you listen, and each one appears once it is decided. After a seek, the server starts again from that point and needs a few seconds to settle (running level, tuning, memory).
    • Your files: streamed to the demo server and decoded live with the same model as they play; some formats are lossy, which changes the chords slightly. No reference annotations exist for them.
    • No scores here: the page shows outputs only. Accuracy figures, measured on validation and test songs, are in the project's reports.
